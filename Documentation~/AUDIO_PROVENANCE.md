# Bundled audio provenance

All WAV files under `Runtime/Resources/Deucarian/Theming/Audio/Defaults` are
original procedural tones generated by `DeucarianDefaultAudioAssetFactory`.
They use only synthesized sine waves, harmonics, and deterministic envelopes;
no third-party recordings, samples, Unity demo assets, or downloaded sounds
are included.

Copyright (c) Deucarian. The clips are distributed under the package MIT
license (`LICENSE.md`) and may be redistributed with applications that consume
`com.deucarian.theming`.

The XR activate and warning tones are independently generated at lower,
softer frequencies than the WebGL defaults. Mobile intentionally silences
hover. Desktop provides separate short key variants. Remaining roles inherit
the Default palette where an experience-specific override adds no value.
